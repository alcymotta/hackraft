# Hackraft

Jogo 3D de blocos no estilo Minecraft, feito para jogar no navegador, em dupla (pai e filho). Roda direto no navegador, sem instalar nada.

## Como rodar localmente

Os módulos do jogo não funcionam abrindo o arquivo direto, então é preciso um servidor local.

- Pelo terminal: `npx --yes serve -l 5173 .` e abrir http://localhost:5173
- Ou pela extensão **Live Server** do VS Code (botão "Go Live").

Abrir o `index.html` com duplo clique não funciona.

## Controles (Fase 1)

- **WASD**: andar
- **Espaço**: pular (e nadar)
- **Shift**: correr
- **Mouse**: olhar
- **Botão esquerdo** (segurado): quebrar bloco
- **Botão direito**: colocar bloco
- **1-9** ou **roda do mouse**: escolher o bloco da barra
- **E**: abrir/fechar o inventário
- **F5**: trocar a câmera
- **F3**: mostrar informações (debug)
- **M**: mudo
- **Esc**: pausar
